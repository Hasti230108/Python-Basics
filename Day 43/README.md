# Day 43 – Pandas Data Operations

Today, I practiced useful **Pandas data operations** using a student DataFrame.

## Topics Covered

### 1. Handling Duplicate Data

* Used `duplicated()` to identify duplicate rows.
* Used `drop_duplicates()` to remove duplicate rows.
* Used the `subset` parameter to check and remove duplicates based on the `Name` column.

### 2. Replacing Values

* Used `replace()` to replace `"Wadala"` with `"Mumbai"` in the `City` column.

### 3. Sorting Data

* Sorted students by marks in ascending order.
* Sorted students by marks in descending order using `ascending=False`.
* Sorted data using multiple columns with `sort_values()`.
* Used different sorting orders with `ascending=[True, False]`.

## Key Concepts Learned

* `duplicated()` helps identify duplicate rows.
* `drop_duplicates()` removes duplicate rows.
* `subset` allows duplicate checking based on specific columns.
* `replace()` changes selected values in a DataFrame.
* `sort_values()` sorts data based on one or more columns.
* `ascending=False` sorts values from highest to lowest.
