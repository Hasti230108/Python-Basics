# Day 77 — Matrix Determinant

Today I learned how to calculate the **determinant of a 2×2 matrix using Python and NumPy**.

## Topics Covered

* Creating a matrix using NumPy
* Taking matrix input from the user
* Accessing matrix elements
* Calculating the determinant of a 2×2 matrix
* Using the determinant formula

## Formula

For a 2×2 matrix:

```text
[a  b]
[c  d]
```

The determinant is:

```text
(a × d) - (b × c)
```
