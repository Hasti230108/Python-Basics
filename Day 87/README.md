# Day 87 — Interactive Student Life Dashboard

Today I built an interactive Student Life Dashboard using Python, Streamlit, Pandas, and NumPy. It displays weekly activity data and allows users to explore study hours, sleep, screen time, and exercise.

## Topics Covered

- Creating a Streamlit web app
- Building an interactive sidebar
- Filtering data using `multiselect()`
- Adjusting values with `slider()`
- Displaying summary metrics using `metric()`
- Analyzing data with Pandas and NumPy
- Creating interactive bar charts
- Generating automatic insights

## Libraries Used

- **Streamlit** — interactive dashboard interface
- **Pandas** — dataset management and filtering
- **NumPy** — numerical calculations and goal analysis

## Features

- Select specific days to analyze
- Set a daily study goal
- View study, sleep, and screen-time statistics
- Compare activities using charts
- Track study-goal progress
- Display automatic weekly insights

## Key Takeaway

This project helped me understand how to turn a Python data-analysis program into an interactive dashboard with filters, metrics, charts, and automatic insights.

The dashboard uses fictional data for practice.
