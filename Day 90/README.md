# Day 90 — Student Task Planner

## Overview

On Day 90, I built a beginner-friendly Student Task Planner using Python and Streamlit. The app allows students to add study tasks, select subjects and priorities, mark tasks as completed, and track their progress.

## Features

- Add study tasks
- Choose a subject
- Set task priority: High, Medium, or Low
- Mark tasks as completed using checkboxes
- View total, completed, and remaining tasks
- Display completion progress with a progress bar

## Concepts Practiced

- Python lists and dictionaries
- `if-else` conditions
- Loops and `enumerate()`
- List methods such as `append()`
- Streamlit input widgets
- `st.session_state`
- Counting completed tasks
- Displaying metrics and progress

## What I Learned

I practised combining Python data structures with Streamlit widgets to create an interactive study planner. I also learned how session state helps retain tasks while the app reruns.

**Note:** Tasks are stored only in the current session and are not permanently saved.
