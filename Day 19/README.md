# Day 19 - Python Built-in Modules (OS Module)

## Overview

Day 19 focuses on understanding Python's built-in modules, especially the **os** module, which allows Python programs to interact with the operating system.
This practice covers basic file and directory management operations using Python and demonstrates how Python interacts with the operating system.

## Topics Covered
- What is a Module?
- Types of Modules
  - Built-in Modules
  - User-defined Modules
  - Third-party Modules
- Introduction to the `os` module

## Functions Practiced
- `os.getcwd()` – Get the current working directory.
- `os.listdir()` – Display all files and folders in the current directory.
- `os.mkdir()` – Create a new directory.
- `os.rename()` – Rename an existing directory.
- `os.rmdir()` – Remove an empty directory.
- `os.path.exists()` – Check whether a file exists.
- `os.path.getsize()` – Get the size of a file.
- `os.remove()` – Delete a file.
