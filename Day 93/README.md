# Day 93 — Random Quote Generator

## About the Project

The **Random Quote Generator** is a simple interactive web app built using Python and Streamlit. It displays a randomly selected quote whenever the user clicks the **Generate Quote** button.

The app contains a collection of motivational quotes to provide a little inspiration throughout the day.

## Features

- Displays the app title and a short introduction.
- Contains a list of 8 motivational quotes.
- Generates a random quote when the button is clicked.
- Displays the selected quote using Streamlit's success message component.
- Shows a positive message at the bottom of the app.

## Technologies Used

- Python
- Streamlit
- Random module

## Concepts Practiced

- Importing Python modules
- Python lists
- `random.choice()` for selecting a random item
- Conditional statements using `if`
- Streamlit UI components such as `st.title()`, `st.header()`, `st.write()`, `st.button()`, `st.success()` and `st.info()`
