# Day 91 - MYSTERY CASE

MYSTERY 100 is a mystery-solving game project where players investigate fictional cases by reading the story, examining clues, and studying different suspects.

The project started as a way for me to learn how to build a real interactive application instead of only creating small practice programs. I wanted to combine programming, logical thinking, storytelling, and problem-solving into one project.

The first prototype represents a mystery case using Python dictionaries and lists.

It displays:

- Case title
- Case story
- Suspects
- Evidence and clues

Python loops are used to display the suspects and clues dynamically.

## Why I Built This

I wanted to create something that feels like a real application and is interesting to work on while learning new programming concepts.

Instead of solving predefined programming exercises, this project gives me a practical problem to build, improve, and experiment with.

## Technologies

- Python
- Dictionaries
- Lists
- Loops
- Basic program output
