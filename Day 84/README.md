# Day 84 — Data Cleaning with Pandas

Today I learned and practised **data cleaning** using Pandas and NumPy.

The program identifies duplicate rows, handles missing values, and cleans text data in a student dataset.

## Topics Covered

- Creating a Pandas DataFrame
- Detecting missing values using `isnull()`
- Identifying duplicates using `duplicated()`
- Removing duplicates using `drop_duplicates()`
- Filling missing values using `fillna()`
- Calculating averages using `mean()`
- Cleaning text using `strip()` and `title()`
- Verifying the cleaned dataset

## Libraries Used

- **Pandas** — data management and cleaning
- **NumPy** — representing missing numerical values using `np.nan`

## Key Takeaway

Data cleaning helps improve data quality by handling missing values, duplicate records, and inconsistent text.
