# Day 113 - Streamlit Calculator

## Project Overview

A simple yet functional calculator built using **Python and Streamlit**. This project started as a basic calculator and gradually evolved into a more complete application with six arithmetic operations, calculation history, CSV export, and improved number formatting.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Power
- Division-by-zero handling
- Modulus-by-zero handling
- Power edge-case handling
- Improved decimal number formatting
- Calculation history
- Clear History functionality
- Download calculation history as a CSV file

## Technologies Used

- Python
- Streamlit
- CSV
- IO

## Concepts Learned

- Python arithmetic operators
- Conditional statements (`if`, `elif`, `else`)
- Functions and reusable code
- Floating-point number formatting
- Exception and edge-case handling
- Python dictionaries and lists
- `enumerate()` and `reversed()`
- Streamlit widgets and buttons
- Streamlit Session State
- CSV file creation using `csv.DictWriter()`
- In-memory file handling using `io.StringIO()`
- File downloads using `st.download_button()`

**Note:** Calculation history is maintained using Streamlit Session State and is temporary. It is not permanently stored by the application.

## 💡 Key Learnings

Through this project, I learned how to build an interactive calculator using Streamlit and gradually improve its functionality.

I also gained practical experience with Python functions, arithmetic operations, conditional logic, data structures, session management, CSV generation, and downloadable files.
