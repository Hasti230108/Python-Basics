# Day 99 — Mystery Data Detective

## About the Project

Mystery Data Detective is a fictional investigation dashboard built using Python, Streamlit, Pandas, and NumPy. It explores a museum mystery involving a missing sapphire.

Users can examine suspect records, filter evidence, compare clues using a chart, and submit their own theory with a written explanation.

## Features

- Fictional suspect and evidence dataset
- Filter suspects by minimum evidence count
- Display case statistics and suspect records
- Compare evidence and clue matches using a bar chart
- Inspect individual suspect details
- Submit a theory with supporting reasoning
- Custom dark theme with colourful accents

## Technologies Used

- **Python** — program logic
- **Streamlit** — interactive dashboard
- **Pandas** — tabular data and filtering
- **NumPy** — generation of fictional evidence scores

## Concepts Practised

- Python dictionaries and variables
- Pandas DataFrames and filtering
- NumPy random number generation
- Streamlit columns, metrics, sliders, select boxes, and buttons
- Conditional statements
- User input and string validation
- Data visualization
- Custom Streamlit themes

## What I Learned

This project helped me combine Python libraries I had learned separately into one interactive application. I practised organizing data, filtering records, displaying charts, and collecting user input through Streamlit.

## Project Note

All suspects, evidence, and scores are fictional. Alibi confidence is a sample score and does not establish guilt or innocence. Submitted theories are displayed during the current session but are not stored permanently.
