## Project

### Student Management System (JSON Based)

A simple CRUD application that stores student records in a JSON file.


## Features

- Add Student
- View Students
- Update Student
- Delete Student
- Exit Program
- Stores records in JSON format
- Reads and writes data from files
- Modular code using `utils.py`
- Handles invalid menu input using Exception Handling

## Concepts Learned

- Difference between Python Dictionary and JSON
- `json.dumps()`
- `json.loads()`
- `json.dump()`
- `json.load()`
- Creating reusable modules
- Reading and writing files
- CRUD operations using lists and dictionaries
- Working with structured data

## Files

### student.py

Contains the complete Student Management System.

### utils.py

Contains helper functions:

- Menu
- Load Students
- Save Students

### student.json

Stores all student records.
