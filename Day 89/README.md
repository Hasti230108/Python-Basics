# Python Day 89 — Streamlit Basics

## Overview

Today I started learning **Streamlit**, a Python framework used to create interactive web applications. I built three beginner-friendly apps to understand how Python code can display information, accept user input, and present data in a browser.

## Files Included

- `streamlit_intro.py` — Displays headings, text, buttons, and messages.
- `student_profile.py` — Collects a student's name, course, and age to create a simple profile.

## Concepts Learned

- Importing Streamlit using `import streamlit as st`
- Displaying text, headings, and messages
- Using buttons, text inputs, select boxes and sliders
- Working with variables and conditional statements
- Running Python scripts as local web applications

## Key Takeaway

This practice helped me understand the basics of Streamlit and how it can turn ordinary Python scripts into interactive applications. These two small projects are my starting point for learning dashboard development and building more useful applications in the future.
