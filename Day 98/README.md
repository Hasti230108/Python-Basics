# Day 98 — Python Text Analyzer

Today I created a simple **Text Analyzer** using Python. This program takes a sentence from the user and displays useful information about the entered text.

## Features

- Takes text input from the user
- Counts the total number of characters
- Counts the total number of words
- Converts text into uppercase and lowercase
- Displays each word separately
- Handles empty input with a simple message

## Concepts Practised

- `input()` — to take user input
- `if-else` — to check whether the input is empty
- `split()` — to separate text into words
- `len()` — to count characters and words
- `upper()` and `lower()` — to change letter case
- `for` loop — to print words one by one

##  What I Learned

I practised working with strings, lists, conditions, and loops. I also learned how to use Python's built-in string methods to process and display text.
