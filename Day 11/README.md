# Day 11 - Modules & Packages

## Topics Covered

- Modules
- Packages (Introduction)
- import
- from ... import ...
- Built-in Modules
- math Module
- random Module
- Creating Custom Modules
- __name__ == "__main__"

## Programs

### 1. math_module.py
- Import the built-in `math` module.
- Find the square root, power, and factorial of a number.

### 2. random_number.py
- Generate a random integer between 1 and 100 using the `random` module.

### 3. random_choice.py
- Select a random fruit from a list using `random.choice()`.

### 4. import_function.py
- Import only the `sqrt()` function from the `math` module.
- Calculate the square root of a user-entered number.

### 5. calculator.py
- Create a custom module containing functions:
  - Addition
  - Subtraction
  - Multiplication
  - Division

### 6. main.py
- Import the custom `calculator` module.
- Call different functions from another Python file.

### 7. greet.py
- Demonstrate the use of:
  - `if __name__ == "__main__":`
- Execute code only when the file is run directly.

## Concepts Learned

- What a Python module is.
- Difference between modules and packages.
- Importing complete modules using `import`.
- Importing specific functions using `from ... import`.
- Using built-in modules like `math` and `random`.
- Creating and importing custom modules.
- Understanding the purpose of `if __name__ == "__main__"`.

## Outcome

Today I learned how Python modules help organize programs into reusable files. I practiced importing built-in modules, creating my own module, and calling functions from another file. I also learned the purpose of `if __name__ == "__main__"` and how it is used while developing larger Python applications.
