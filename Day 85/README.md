#  Day 85 — Expense Intelligence Analyzer

Today I built an **Expense Intelligence Analyzer** using NumPy, Pandas, and Matplotlib to analyze spending patterns and visualize expense distribution.

## Topics Covered

- Creating a Pandas DataFrame
- Calculating total, average, highest, and lowest expenses using NumPy
- Grouping expenses by category using `groupby()`
- Sorting expenses using `sort_values()`
- Finding the highest-spending category using `idxmax()`
- Visualizing expenses with bar and pie charts

## Libraries Used

- **NumPy** — numerical calculations
- **Pandas** — data analysis and grouping
- **Matplotlib** — data visualization

## Key Takeaway

Combining NumPy, Pandas, and Matplotlib helps transform raw expense data into meaningful summaries and visual insights.
