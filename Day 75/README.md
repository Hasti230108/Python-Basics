## Adjoint of a 2×2 Matrix

For:

```text
[a  b]
[c  d]
```

The adjoint is:

```text
[d  -b]
[-c  a]
```

## Example

```text
Original Matrix:
[[3 5]
 [1 8]]

Adjoint Matrix:
[[ 8 -5]
 [-1  3]]
```
