# Day 37 – NumPy Random Sampling & Distributions

## Topics Covered
- Random number generation using `np.random.default_rng()`
- Uniform distribution using `rng.uniform()`
- Normal distribution using `rng.normal()`
- Random sampling with a fixed seed
- Mean, median, minimum and maximum
- Standard deviation
- Filtering values using conditions
- Standard normal distribution
- Working with large random datasets

## File
`numpy_random_sampling_distributions.py`

## Key Functions
- `np.random.default_rng(42)` – creates a reproducible random generator
- `rng.uniform()` – generates uniformly distributed random values
- `rng.normal()` – generates normally distributed random values
- `np.mean()` – calculates mean
- `np.median()` – calculates median
- `np.min()` – finds minimum
- `np.max()` – finds maximum
- `np.std()` – calculates standard deviation

## Practice
Generated random student marks, analyzed their statistics, filtered students between 60 and 80, and generated standard normal data.
