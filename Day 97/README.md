# Day 97 — My Color Studio

Today I built **My Color Studio**, an interactive colour exploration app using Python and Streamlit.

The app allows users to choose a colour, view its HEX and RGB values, preview it, and explore a small collection of colour swatches.

## Features

- **Colour Picker:** Choose a favourite colour using Streamlit's colour picker.
- **HEX Code:** Display the selected colour's HEX code.
- **HEX to RGB Conversion:** Convert the HEX code into its Red, Green, and Blue values.
- **Colour Preview:** Display a large preview of the selected colour.
- **Colour Palette:** Explore four colours: Pink, Lavender, Mint, and Sky Blue.
- **Selected Colour Code:** Display the selected HEX code in a code-style box.

## Technologies Used

- Python
- Streamlit

## Concepts Practised

- Using Streamlit components
- Creating a colour picker
- Working with strings using `lstrip()`
- Converting hexadecimal values to integers
- Using Python f-strings
- Displaying HTML-based colour previews
- Arranging elements using `st.columns()`

## What I Learned

I learned how to convert HEX colour codes into RGB values and use Streamlit to build a simple visual application. I also practised displaying colours and organising interface elements into columns.
