# Day 14 - Inheritance

## Topics Covered

- Inheritance
- Parent Class
- Child Class
- Multilevel Inheritance
- Method Reusability
- super() Function
- User Input with Inheritance
- Object Creation

## Programs

### 1. student_inheritance.py
- Created a `Person` class.
- Created a `Student` class inheriting from `Person`.
- Used `super()` to reuse the constructor.
- Displayed student information after inheriting common details.

### 2. employee_manager.py
- Created an `Employee` class.
- Created a `Manager` class inheriting from `Employee`.
- Added department and team size.
- Displayed manager details.

### 3. library_system.py
- Created a `Book` class.
- Created an `IssueBook` class inheriting from `Book`.
- Allowed the user to issue a book.
- Displayed issued book information.

### 4. multilevel_inheritance.py
- Created three classes:
  - Person
  - Employee
  - Manager
- Implemented Multilevel Inheritance.
- Used conditional logic to determine whether a person is:
  - Person
  - Employee
  - Manager
- Displayed information accordingly.

## Concepts Revised

- Parent and Child Classes
- Reusing code using Inheritance
- Constructor chaining using `super()`
- Multilevel Inheritance
- Creating objects of different classes
- Interactive inheritance programs
- Improving code reusability

## Outcome

Today I revised how inheritance allows child classes to reuse properties and methods from parent classes, making programs cleaner and easier to maintain. I practiced creating parent, child, and multilevel inheritance structures using `super()`. I also built interactive programs where object creation depends on user input, helping me understand how inheritance is used in real-world applications.
