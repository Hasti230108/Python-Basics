# Day 107 -Streamlit Web App

Today I converted my SpamShield SMS classification model into an interactive web application using **Streamlit**.

The app allows users to enter an SMS message and receive a prediction from my trained **TF-IDF + Multinomial Naive Bayes** model.

## Project Goal

Build a simple web interface that can:

- Accept an SMS message from the user.
- Convert the message into TF-IDF features.
- Predict whether the message is `ham` or `spam`.
- Display the spam probability.
- Show a warning if the input is empty.

## Technologies Used

- Pandas

| `data/` | Contains the SMS Spam Collection dataset |

## How the Application Works

1. The trained model and vectorizer are loaded using Joblib.
2. Streamlit displays a text area for entering an SMS.
3. The entered message is transformed using the saved TF-IDF vectorizer.
4. The Naive Bayes model predicts the message category.
5. `predict_proba()` calculates the spam probability.
6. The app displays the prediction and probability.

### Prediction Logic

- `ham` → Legitimate message according to the trained model.
- `spam` → Spam message according to the trained model.

The prediction depends on patterns learned from the training dataset. It is not a guarantee that every real-world promotional or suspicious message will be identified correctly.

## Concepts Learned

- Building a web app using Streamlit
- Using `st.title()` and `st.subheader()`
- Creating input fields with `st.text_area()`
- Handling button submissions with `st.form_submit_button()`
- Displaying results with `st.success()` and `st.error()`
- Showing numerical results with `st.metric()`
- Saving and loading ML models using Joblib
- Reusing a trained model without training it again for every prediction
- Caching model resources with `@st.cache_resource`

## Key Takeaways

> Streamlit makes it possible to turn Python programs into interactive web applications.

> A trained machine learning model can be saved and reused with Joblib.

> TF-IDF converts text into numerical features that the model can process.

> Model predictions depend on the patterns learned from the dataset.
