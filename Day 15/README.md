## Programs

### 1. shape_polymorphism.py
- Created a parent class `Shape`.
- Created child classes:
  - Rectangle
  - Square
  - Circle
- Overrode the `area()` method in every class.
- Calculated area for different shapes.

### 2. math_calculator.py
- Used Python's `math` module.
- Calculated:
  - Square Root
  - Factorial
  - Power
  - Ceiling
  - Floor
  - Pi

### 3. random_password.py
- Generated a random password.
- Used `random.choice()` to create a secure password.

### 4. lucky_draw.py
- Accepted student names.
- Randomly selected one winner using `random.choice()`.

### 5. datetime_age.py
- Calculated age using the current year.
- Used the `datetime` module.

### 6. digital_clock.py
- Displayed the current date.
- Displayed the current time.
- Used `strftime()` formatting.

### 7. os_info.py
- Displayed the current working directory.
- Displayed all files inside the current folder.

### 8. statistics_marks.py
- Accepted five subject marks.
- Calculated:
  - Mean
  - Median
  - Highest Marks
  - Lowest Marks

### 9. mini_utility.py
- Generated random numbers.
- Calculated mean.
- Calculated square root of the mean.
- Displayed the current time.

### 10. Student Report Generator (srg.py)
- Accepted student details.
- Generated random marks.
- Calculated:
  - Average
  - Median
  - Square Root of Average
- Displayed report generation date and time.
