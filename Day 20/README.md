## Programs

### 1. Collections Module Practice

A practice program demonstrating Python's `collections` module.

#### Concepts Implemented

##### Counter
- Counts the frequency of characters in a string.
- Finds the most repeated character.

##### defaultdict
- Automatically creates default values for missing keys.
- Demonstrates `list` and `int` as default factories.

##### deque
- Double Ended Queue.
- Performs operations such as:
  - append()
  - appendleft()
  - pop()
  - popleft()

##### namedtuple
- Creates tuples with named fields.
- Demonstrates storing and accessing person details using attribute names.

## Concepts Learned

- Understanding Python's `collections` module.
- Counting element frequencies using `Counter`.
- Creating dictionaries with automatic default values using `defaultdict`.
- Performing efficient queue operations using `deque`.
- Creating readable tuples using `namedtuple`.
- Understanding real-world uses of advanced Python data structures.
