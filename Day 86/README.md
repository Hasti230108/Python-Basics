# Day 86 — Student Life Analyzer

Today I built a **Student Life Analyzer** using Python, NumPy, Pandas, and Matplotlib. The project analyzes a student's fictional weekly routine to compare study hours, sleep, screen time, and exercise.

## Topics Covered

- Creating a Pandas DataFrame
- Converting Pandas columns into NumPy arrays
- Calculating totals, averages, maximums, and minimums
- Finding specific days using `idxmax()`
- Creating new columns through calculations
- Comparing daily activities
- Visualizing data using bar charts and line plots
- Generating automatic insights from data

## Libraries Used

- **NumPy** — numerical calculations
- **Pandas** — storing and analyzing weekly routine data
- **Matplotlib** — creating charts and visual comparisons

## Project Features

- Displays a seven-day routine dataset
- Calculates weekly study hours and average activity times
- Identifies days with the highest study, screen, and sleep hours
- Compares study time with screen time
- Creates two charts to visualize activity patterns

## Key Takeaway

This project helped me practice combining Python libraries to turn a simple dataset into meaningful statistics, comparisons, and visual insights.

The dataset uses fictional values for practice and does not represent real student behaviour.
