# Day 74 — Find Duplicate Elements

Today I practiced finding duplicate elements in a list using Python dictionaries.

### Concept Covered

- Lists
- Dictionaries
- Frequency counting
- `for` loops
- `if-else`
- Detecting duplicate elements

### Approach

First, I took numbers from the user and stored them in a list.

Then I created a dictionary called `frequency` to count how many times each number appears.

If a number already exists in the dictionary, its count is increased. Otherwise, it is added with a count of 1.

Finally, I checked which numbers appeared more than once and displayed their frequency.

### Key Takeaway

A dictionary is useful for storing and counting the frequency of elements efficiently.
